# Code of Conduct

This project is a friendly place to get help with Unraid and n8n and to build tools for them. Everyone who joins in, in issues, discussions, pull requests and reviews, is expected to help keep it that way.

## Expected

- Be respectful and patient, especially with newcomers and people writing in a second language.
- Assume good intent. Ask questions before drawing conclusions.
- Give constructive, specific feedback on code and ideas, not on people.
- Respect people's time: search existing issues first and give the details asked for.
- Respect privacy: never post someone else's logs, keys or personal data.

## Not acceptable

- Harassment, insults, or discriminatory or sexual language and imagery.
- Personal or political attacks, trolling, and repeatedly derailing threads.
- Publishing others' private information, keys or credentials.
- Spam, advertising, or pushing paid services in support threads.
- Asking for, or sharing, ways to attack other people's servers.

## Enforcement

Maintainers may edit or delete comments, close or lock threads, and temporarily or permanently block anyone who breaks these rules. To report a problem privately, contact the maintainer through their [GitHub profile](https://github.com/SilentJMA). Reports are kept confidential.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
